Simulating American-option values requires a volatility input at every date along a stock path. In this study, we developed a framework that supplied this input while allowing the stock-return model to be chosen separately. Fitted neural surfaces set targets for contract-specific implied-volatility (IV) factors along JumpHMM stock paths with truncated return emissions, and an American lattice converts each state into option values and price sensitivities. Sector-specific surfaces reduced in-sample IV error relative to a global parametric surface on 234,549 observations from 31 tickers. A paired ablation showed that IV dynamics changed interim marks on identical stock paths while preserving terminal payoffs. Temporal evaluation included 53 surface folds and a July-cutoff fit tested against August–September 2026 observations. Five-session option forecasts used 17 origins per ticker. The coupled factor lowered mean-forecast absolute errors for Goldman Sachs and Eli Lilly only marginally relative to frozen IV. Supplying subsequently observed stock paths reduced option errors in a diagnostic that used future information. Separate stock tests covered 245 five-session origins per ticker in 2025 and 17 in 2026. Central forecasts remained close to an unchanged-price benchmark. Adaptive volatility improved Eli Lilly's distribution scores in both periods but not Goldman Sachs's, and earlier validation selected zero drift for a simple directional model. The framework supports controlled comparisons of IV assumptions; these tests did not establish a consistent forecasting advantage. Incomplete contract histories, dependent forecast dates, and residual strike inconsistencies limited broader conclusions.
