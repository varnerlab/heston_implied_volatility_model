\section*{Data and Code Availability}\label{sec:data_availability}

All data, code, and saved results for this study are available at \url{https://github.com/varnerlab/heston_implied_volatility_model}. The repository contains the daily option-chain snapshots from April 14 through September 4, 2026, the daily stock prices, the earnings calendar, and the pretrained JumpHMM model. It also contains the scripts that fit the IV surfaces, run the simulations and tests, and summarize their results, together with the saved outputs and logs. The repository's \texttt{README.md} gives the command for each experiment, and \texttt{SETUP.md} lists the setup steps. The option quotes come from Alpaca's free indicative feed, a modified version of the exchange feed, so they may differ from exchange quotes~\cite{alpaca_option_feed}. The code is released under the MIT License.
