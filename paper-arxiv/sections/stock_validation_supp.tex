\section{Stock Forecast Evaluation}\label{sec:stock_validation_supp}

The saved GS and LLY models used daily steps of $1/252$ year and annualized excess log returns. Reconstructing the first-origin forecasts reproduced the saved stock means at both one and five sessions. In the initialization check, we inferred the current hidden state from the available daily returns and advanced it before generating the first future return. The inference tracked both the return state and the number of forced tail-state emissions left in a jump episode. Poisson durations kept all but at most $10^{-12}$ of the probability, with the remainder assigned to the final duration. A missing day advanced the hidden-state distribution without an observation likelihood. A return accumulated over several days was never treated as a daily observation. We removed the fixed pilot growth shift from observed annualized returns before computing likelihoods, to match the simulated observation model. We compared this conditional start with the original start on the same 2026 endpoints (Table~\ref{tab:stock_initialization}). Both used three 10{,}000-path runs, with seeds separate from the four-method benchmark. The fitted transitions mixed the hidden states within a few sessions, so the conditional start had little effect on five-session central forecasts. Other exploratory checks, including a fixed 20-return volatility adjustment and Gaussian random walks, are kept in the saved experiment outputs.

The benchmark comparison kept JumpHMM's fitted parameters and truncated emissions and tested one adaptive variance rule and one directional model against it. For each annual validation block from 2019 through 2024, regression training responses ended before the validation year and validation endpoints remained within it. The EWMA variance began with the sample variance of the first sixty training daily returns and then updated using only returns observed by each origin. Decay selection minimized $\tfrac12[\log(h a_t)+y_{t,h}^2/(h a_t)]$, where $y_{t,h}$ was the observed cumulative log return over $h$ sessions. We first averaged this loss within each ticker, validation year, and horizon, then gave the resulting groups equal weight. With the selected decay, the regression fitted the next daily return divided by origin volatility. Its four features were the stock's last daily return, its last five- and twenty-return sums, and SPY's last five-return sum. Return sums were divided by the origin volatility and the square root of the window length. Each feature column was then divided by its training root mean square. The ridge objective was the mean squared normalized one-session error plus the penalty times the squared coefficient norm, with no intercept. Penalty selection used $(y_{t,h}-h\widehat\mu_t)^2/(h a_t)$, with the same group weighting as decay selection. The zero-drift limit had the lowest validation loss and set all four coefficients to zero for both tickers (Table~\ref{tab:stock_selection}). Final coefficients and feature scales were fitted using 2014--2024 only and saved before evaluating test forecasts. The two selection losses measure different things, so their magnitudes cannot be compared.

Historical close series for GS, LLY, and SPY shared the same recorded session grid, with 2{,}767 closes per ticker in 2014--2024 and 250 in 2025. The 2025 test updated lag features and variance using information through each origin while keeping fitted parameters fixed. The 2026 series began in April after a data gap. Its variance restarted from the 2014--2024 sample estimate and updated through the available April--July daily returns before evaluation. No daily return spanned the gap from December 2025 to April 2026. Within 2026, a daily return required closes on both adjacent trading sessions, and a missing observation left the variance unchanged. Feature windows used the last required number of valid daily returns, which could span more sessions when observations were missing. The oldest feature input at an evaluated 2026 origin was four calendar days old, whereas the 2025 features had no such gap. Complete five-session and one-session scores cover all four candidates and both periods (Tables~\ref{tab:stock_validation_five} and~\ref{tab:stock_validation_one}). The directional and adaptive rows agree exactly because zero drift was selected. Their small median-error differences from the unchanged-price benchmark are Monte Carlo noise, since the population median of their forecast distribution equals the origin price. The saved outputs include seed-level scores, date-level comparisons, input hashes, and settings. The three seeds measure simulation variation alone.
